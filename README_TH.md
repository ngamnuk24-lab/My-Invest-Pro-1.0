# My Invest v2.0 — Multi-Market Edition

## ความสามารถ
- พัฒนาต่อจาก My Invest v1.1 โดยคง IndexedDB ชื่อ `my-invest-db` และ DB version 2 เพื่อเปิดข้อมูลเดิมต่อได้
- รองรับตลาดสหรัฐฯ (USD), ไทย (THB), ญี่ปุ่น (JPY), ฮ่องกง (HKD), สหราชอาณาจักร (GBP), แคนาดา (CAD), เกาหลีใต้ (KRW), ไต้หวัน (TWD) และตลาดอื่นผ่าน Yahoo symbol ที่ผู้ใช้ระบุ
- ตัวอย่างรหัส: AAPL (US), PTT (ไทย ระบบเติม .BK ตอนค้นราคา), 7203 (ญี่ปุ่น ระบบเติม .T), 0700 (ฮ่องกง ระบบเติม .HK), VOD (อังกฤษ ระบบเติม .L), SHOP (แคนาดา ระบบเติม .TO), 005930 (เกาหลี ระบบเติม .KS), 2330 (ไต้หวัน ระบบเติม .TW)
- ราคาหุ้น ต้นทุน มูลค่ารายการ และกำไร/ขาดทุนแสดงสกุลเงินต้นทางพร้อมวงเล็บรหัสสกุลเงิน และแสดงมูลค่า/ผลรวมเทียบ THB
- กำไร/ขาดทุนเป็นสีเขียวเมื่อเป็นบวก และสีแดงเมื่อเป็นลบ
- ประวัติซื้อขายกรองวันที่เริ่มต้น/สิ้นสุด และกรองตามตลาดได้
- ราคากลาง แก้ไขราคาเองได้; เก็บราคาและ FX ในเครื่องเพื่อใช้เมื่อออฟไลน์
- สำรอง/กู้คืน JSON, Service Worker และติดตั้งเป็น PWA บน iPhone ได้

## วิธีคิด
- FX เก็บเป็นจำนวน THB ต่อ 1 หน่วยสกุลเงินต้นทาง ณ เวลาบันทึก
- BUY: ต้นทุนเงินบาท = (จำนวน × ราคาต่อหน่วย + ค่าธรรมเนียม) × FX
- SELL: กำไร/ขาดทุนเงินบาทคำนวณด้วยวิธี Average Cost
- มูลค่าพอร์ตปัจจุบัน = จำนวนคงเหลือ × ราคาล่าสุดในสกุลต้นทาง × FX ปัจจุบัน
- เงินปันผลคิดเป็นกำไร/ขาดทุนที่รับรู้แล้ว

## ข้อจำกัดราคาและ FX
- ราคาดึงจาก Yahoo Finance Chart ผ่าน CORS proxy สาธารณะ ซึ่งเป็น endpoint ไม่เป็นทางการ อาจล่าช้า เปลี่ยนแปลง จำกัดการเรียก หรือไม่มีข้อมูลบางสัญลักษณ์/ตลาด จึงไม่รับประกัน Real-time
- รูปแบบ suffix ที่ใช้เป็นค่าเริ่มต้นตาม Yahoo Finance: ไทย `.BK`, ญี่ปุ่น `.T`, ฮ่องกง `.HK`, อังกฤษ `.L`, แคนาดา `.TO`, เกาหลี `.KS`, ไต้หวัน `.TW` ผู้ใช้ควรตรวจสอบรหัสที่ Yahoo รองรับ
- FX ใช้ Frankfurter เมื่อมีข้อมูล; บางสกุลเงินอาจไม่อยู่ในบริการ จึงอาจคงค่าเดิม/ค่าเริ่มต้นโดยประมาณไว้ ผู้ใช้สามารถแก้ FX ในแบบฟอร์มก่อนบันทึกได้
- หากไม่สามารถดึงราคาหรือ FX ได้ แอปจะใช้ค่าล่าสุดที่เก็บในเครื่องหรือให้แก้ไขราคาเอง
- ข้อมูลทั้งหมดอยู่ใน IndexedDB ของเบราว์เซอร์ ไม่ได้ซิงก์อัตโนมัติระหว่างอุปกรณ์ ควรส่งออก JSON สำรองเป็นระยะ
- ตรวจสอบราคากับโบรกเกอร์ก่อนส่งคำสั่งซื้อขายเสมอ

## อัปเกรดจาก v1.1
- ใช้ฐานข้อมูลเดิมและไม่ล้างข้อมูลเดิม รายการเดิมที่ไม่มี `market`/`currency` จะถือเป็น US/USD โดยอัตโนมัติ
- ราคาหุ้นเดิมที่ไม่มี `market` จะถือเป็นราคา US/USD
- แนะนำให้ส่งออก JSON จากแอปเดิมก่อนอัปเกรดเพื่อความปลอดภัย

## ติดตั้งบน iPhone
1. แตก ZIP แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์ `my_invest_pwa` ไปยังเว็บโฮสต์ที่รองรับ HTTPS
2. เปิด URL ด้วย Safari ขณะออนไลน์ครั้งแรก รอให้โหลดครบ
3. กด Share → Add to Home Screen (เพิ่มไปยังหน้าจอโฮม)
4. เปิดแอปจากไอคอนบนหน้าจอ และกด “อัปเดตราคาและ FX”
5. ใช้เมนูตั้งค่า → ส่งออกข้อมูล เพื่อสำรองไฟล์ JSON เป็นระยะ
